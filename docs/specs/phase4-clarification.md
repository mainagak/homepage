# フェーズ4着手前 曖昧さ撲滅ラウンド

フェーズ3(利用アーキテクチャー調査)確定後、フェーズ4(内部仕様調査)に着手する前に、
残存する曖昧・未定・「想定」止まりの論点をユーザーの明示的指示により3択形式で完全に
潰す。50問×3ラウンドを想定。本ドキュメントはその記録。

## 進め方

- 各ラウンド50問、すべて3択(A/B/C)形式。
- ユーザーは番号+選択肢(例: `1-A, 2-C, ...`)で回答する。
- 回答を反映し、必要なら`external-spec.md`・`architecture.md`に軽微修正を加える。
- 3ラウンド終了後、フェーズ4(p4-internal-spec-researcher)に着手する。
